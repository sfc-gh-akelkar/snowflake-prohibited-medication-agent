Query Resolution Flow

How the agent answers: "Is Lipitor prohibited in Protocol MPC-ONC-001?"

1 Resolve Name Cortex Search matches "Lipitor" to DrugBank ID DB00439 (Atorvastatin)
2 Classify Drug Lookup: DB00439 belongs to category "HMG-CoA Reductase Inhibitors" (Statins)
3 Check Rules Query protocol prohibition table: Is "Statins" prohibited in MPC-ONC-001?
4 Return Answer NOT PROHIBITED. Statins are not in the exclusion list for this oncology trial.

Key Design Decision: No graph database required. The drug-to-prohibition traversal is 2-3 SQL joins (drug → category → protocol prohibition rule). Cortex Search handles fuzzy name resolution at ~100ms latency. The full solution runs natively in Snowflake with zero external dependencies.

Why This Architecture

No External MCP All data and compute inside Snowflake. No production dependency on external services.
No Neo4j Needed 2-3 hop traversal is a SQL join problem, not a graph problem. Saves infrastructure cost and complexity.
AI-Powered Matching Cortex Search resolves messy EDC text (brand names, abbreviations, misspellings) to canonical drug IDs.
Declarative Rules New protocol? Just add rows to PROTOCOL_PROHIBITED_CLASSES. No code changes required.
Always-Current Data DrugBank via live share, FDA via marketplace listing. Zero ETL for reference data.
Governance Preserved Snowflake RBAC, masking policies, and row access policies apply through the agent layer.
